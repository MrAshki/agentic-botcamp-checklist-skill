# نقشه موضوع و منابع دوره

این فایل برای انتخاب مرجع و نوشتن بخش «منابع مرتبط دوره» است. برچسب‌های «ج۰» تا «ج۵» در اسلایدها یعنی جلسهٔ صفر تا پنج؛ آن‌ها را با شناسه‌های داخلی C اشتباه نگیر.

فقط مرجع جلسه‌ای را بخوان که بر تصمیم یا چک‌لیست پاسخ اثر دارد. برای یک پاسخ معمولی، دو تا چهار جلسه کافی است. نام رسمی جلسه و موضوع استفاده‌شده را نشان بده؛ نام فایل و شناسه داخلی را نشان نده.
