# نقشهٔ ارجاع خوانا به دوره

این فایل برای نوشتن بخش «ارتباط با دوره» است. برچسب‌های «ج۰» تا «ج۵» در تصاویر یعنی جلسهٔ ۰ تا جلسهٔ ۵. این برچسب‌ها را با شناسه‌های داخلی C اشتباه نگیر.

فقط جلسه و موضوعی را ذکر کن که روی مسیر یا چک‌لیست پاسخ اثر داشته است. نام کلی جلسه کافی نیست؛ ارتباط آن با پاسخ را نیز کوتاه بنویس.

- جلسهٔ ۰، نقشهٔ AI — توانایی‌ها، ریسک‌ها، قوانین، ایران و محدودیت دسترسی.
- جلسهٔ ۱، داده — قالب داده، EDA، کیفیت، Split، Leakage و آماده‌سازی داده.
- جلسهٔ ۲، ML و یادگیری عمیق — مدل‌های کلاسیک، Transformer، CNN، RNN، ASR، معیارها و Fine-tune مدل‌های متنی.
- جلسهٔ ۳، API تا RAG — LLM، Prompt، Context، API، OAuth، Backend، خروجی ساختاریافته، Embedding، Vector DB و RAG.
- جلسهٔ ۴، Agent — Workflow یا Agent، ابزار و MCP، حافظه، چند-Agent، خودمختاری، Tracing، Eval، OWASP و دستیار شخصی.
- جلسهٔ ۵، مدل باز — مجوز، API در برابر مدل محلی، سخت‌افزار، Quantization، runtimeهای محلی، Harness و Fine-tune.

موضوع‌های عرضی مانند هزینه و تأخیر، Git، Docker، SQL، مستندسازی و ارائه می‌توانند در چند جلسه کاربرد داشته باشند. اگر تصویر یا مرجع یک برچسب جلسهٔ مشخص دارد، همان جلسه را ترجیح بده. اگر منبع مستقیم روشن نیست، آن را به جلسه‌ای نسبت نده و در صورت نیاز با عنوان «تکمیل اسکیل» بیان کن.

## الگوی نگارش

- «جلسهٔ ۴، Agent — انتخاب Workflow ابزارمحور به‌جای Agent خودمختار.»
- «جلسهٔ ۲، ML و یادگیری عمیق — استفاده از ASR برای تبدیل صوت به متن.»
- «جلسهٔ ۳، API تا RAG — اتصال APIها و تعریف خروجی ساختاریافته.»
- «جلسهٔ ۵، مدل باز — مقایسهٔ هزینه و محدودیت اجرای محلی با API.»

نام فایل، شناسهٔ C، شناسهٔ A و شمارهٔ اسلاید را پیش‌فرض به کاربر نشان نده. این جزئیات را فقط برای درخواست ردیابی یا ممیزی منبع اضافه کن.
