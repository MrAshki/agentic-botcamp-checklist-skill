# جلسهٔ ۲ — یادگیری ماشین، از کل به جزء

## چه وقت این مرجع را بخوان

برای تشخیص نوع مسئله، انتخاب مدل، ML کلاسیک، متن، تصویر، صوت، ASR، مدل آماده، معیار، Cross-Validation، Overfitting یا نگاشت مدل تخصصی به ابزار Agent.

## قواعد تصمیم‌ساز

- داده برچسب‌دار به رگرسیون یا دسته‌بندی می‌رود؛ داده بدون برچسب می‌تواند خوشه‌بندی، کاهش بُعد، پیشنهاد یا تشخیص ناهنجاری باشد.
- چرخه پروژه شامل تعریف مسئله، داده، پاک‌سازی، ویژگی، آموزش، ارزیابی، استقرار و پایش است. مدل فقط یک مرحله است.
- برای داده جدولی از Baseline ساده شروع کن. Linear یا Logistic، Random Forest و Gradient Boosting کاندیدهای رایج‌اند.
- برای متن، TF-IDF با مدل کلاسیک Baseline مفید است. Fine-tune مدل آماده فقط پس از اثبات بهبود و وجود داده و منابع مطرح شود.
- برای تصویر و صوت، انتقال یادگیری یا مدل آماده را پیش از آموزش از صفر بررسی کن.
- وظایف NLP را به برچسب کل متن، برچسب توکن یا تبدیل دنباله به دنباله تفکیک کن.
- در ASR، زبان، لهجه، نویز، متن مرجع و WER یا CER را روی صوت واقعی پروژه آزمایش کن.
- Underfitting و Overfitting را با نتیجه Train و داده ندیده تشخیص بده.
- Train وزن‌ها را یاد می‌گیرد؛ Validation انتخاب می‌کند؛ Test فقط سنجش نهایی است.
- Accuracy برای کلاس نامتوازن کافی نیست. Precision، Recall، F1، PR-AUC یا معیار رگرسیون را با هزینه خطا انتخاب کن.
- مدل آماده، API یا مدل محلی باید با داده، بودجه، زمان و سخت‌افزار مقایسه شود. نبود GPU نقص پروژه نیست.
- در سیستم Agentic، دسته‌بند می‌تواند Router، NER می‌تواند استخراج پارامتر، ASR ورودی صوتی و مدل جدولی یک Tool تخصصی باشد.
