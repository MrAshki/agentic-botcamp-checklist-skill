# جلسهٔ صفر — از تورینگ تا Agent

## چه وقت این مرجع را بخوان

برای تعیین مرز AI، شناخت توانایی و ریسک، انتخاب Workflow یا Agent، محدودیت دسترسی در ایران، هزینه Token، مسیر یادگیری یا آماده‌سازی Demo Day.

## قواعد تصمیم‌ساز

- AI، ML، Deep Learning، GenAI و LLM یک چیز نیستند؛ مسئله را پیش از انتخاب فناوری مشخص کن.
- رشد مدل از داده، محاسبه، الگوریتم، سرمایه و استعداد اثر می‌گیرد. بزرگ‌بودن مدل به‌تنهایی تضمین کاربرد نیست.
- Transformer، Token، Context Window، Temperature و Embedding مفاهیم پایه‌اند؛ فقط مفهوم لازم برای تصمیم کاربر را توضیح بده.
- مرز توانایی AI ناهموار است. موفقیت در یک کار را به کار دیگر تعمیم نده و هر وظیفه را جدا ارزیابی کن.
- ML کلاسیک برای داده جدولی همچنان انتخاب مهمی است.
- API برای عملیات پایدار و قابل‌کنترل، معمولا از Computer Use مطمئن‌تر است.
- Workflow وقتی مناسب است که مسیر معلوم باشد. Agent وقتی ارزش دارد که مدل باید قدم بعدی یا ابزار را انتخاب کند.
- Multi-Agent هزینه هماهنگی و خطا را افزایش می‌دهد و فقط با نقش‌های واقعا مستقل توجیه می‌شود.
- عمل پرخطر به Human-in-the-loop، اختیار محدود و ثبت رویداد نیاز دارد.
- Hallucination، Prompt Injection، نشت داده، دسترسی زیاد، هزینه Token و تأخیر باید متناسب با پروژه بررسی شوند.
- شرایط دسترسی، تحریم، قانون و سرویس در ایران ممکن است مسیر را تغییر دهند؛ وضعیت روز را بدون بررسی قطعی اعلام نکن.
- برای Demo Day، مسئله، ارزش، نتیجه قابل‌نمایش، محدودیت و روایت روشن مهم‌تر از تعداد فناوری‌ها هستند.
