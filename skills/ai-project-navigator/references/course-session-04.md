# جلسهٔ ۴ — Agentic AI در عمل

## چه وقت این مرجع را بخوان

برای Workflow یا Agent، ReAct، Context Engineering، ابزار، MCP، حافظه، State، Multi-Agent، خودمختاری، Prompt Injection، Eval، Trace و اقدام بیرونی.

## قواعد تصمیم‌ساز

- از نردبان LLM ساده، LLM تقویت‌شده، Workflow، Agent و Multi-Agent بالا برو؛ هر پله باید نیاز و Eval داشته باشد.
- Workflow مسیر معلوم دارد. Agent قدم بعدی و ابزار را پویا انتخاب می‌کند.
- حلقه Agent شامل Observe، Think و Act است و باید سقف قدم، Timeout، بودجه و شرط توقف داشته باشد.
- Context را انتخاب، فشرده، ذخیره یا جدا کن. تاریخچه نامحدود می‌تواند Context Rot ایجاد کند.
- Working Memory برای وظیفه جاری است. حافظه بلندمدت باید منبع، دامنه، زمان و امکان حذف داشته باشد.
- Function Calling پیشنهاد مدل است؛ کد باید نام ابزار و آرگومان‌ها را اعتبارسنجی کند.
- ابزار باید Schema، Allowlist، کمترین دسترسی، خروجی ساختاریافته و جداسازی خواندن از نوشتن داشته باشد.
- MCP استاندارد اتصال است، نه تضمین امنیت. Server شخص ثالث مانند کد شخص ثالث بررسی شود.
- Single-Agent پیش‌فرض است. Multi-Agent فقط برای نقش، Context یا مجوز واقعا متفاوت توجیه می‌شود.
- سطح خودمختاری را با هزینه خطا و برگشت‌پذیری تنظیم کن. عمل حساس به تأیید انسان نیاز دارد.
- Prompt Injection می‌تواند از پیام، سند، ایمیل، وب یا خروجی ابزار بیاید. دفاع باید در ورودی، مدل، ابزار، اجرا، خروجی و عملیات باشد.
- Agent را در سطح Unit، Trajectory، Outcome، Safety و Human Review ارزیابی کن.
- Trace باید Prompt، مدل، Tool Call، پاسخ ابزار، خطا و نتیجه را وصل کند؛ Secret و PII را ثبت نکن.
