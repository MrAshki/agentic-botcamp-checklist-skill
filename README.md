## نصب سریع

### یک خط داخل ایجنت خودتان کپی کنید

یکی از خط‌های زیر را در گفت‌وگوی همان ابزار بفرستید. ایجنت راهنمای نصب ریپو را می‌خواند، نصب می‌کند و نتیجه را بررسی می‌کند. این روش به محیطی با دسترسی وب/ترمینال و اجازهٔ نوشتن فایل نیاز دارد؛ ارسال آن در چت معمولی بدون ابزار، نصب ایجاد نمی‌کند.

**Codex**

```text
اسکیل ai-project-navigator را از https://github.com/MrAshki/agentic-botcamp-checklist-skill طبق INSTALL.md برای Codex در سطح کاربر نصب کن و صحت نصب را بررسی کن.
```

**Gemini CLI**

```text
اسکیل ai-project-navigator را از https://github.com/MrAshki/agentic-botcamp-checklist-skill طبق INSTALL.md برای Gemini CLI در سطح کاربر نصب کن و صحت نصب را بررسی کن.
```

**Claude Code**

```text
اسکیل ai-project-navigator را از https://github.com/MrAshki/agentic-botcamp-checklist-skill طبق INSTALL.md برای Claude Code در سطح کاربر نصب کن و صحت نصب را بررسی کن.
```

### یا یک فرمان در ترمینال اجرا کنید

پیش‌نیاز: **Git و Node.js نسخهٔ 22.20 یا جدیدتر، همراه npm/npx** و ابزار مقصد با قابلیت Agent Skills. از یک نسخهٔ LTS سازگار Node.js استفاده کنید. این اسکیل به سرور، GPU، کلید API یا نصب کتابخانهٔ ML نیاز ندارد؛ هزینهٔ استفاده از مدل تابع سرویس خودتان است.

فرمان‌ها از [`skills`](https://github.com/vercel-labs/skills)، نصب‌کنندهٔ مشترک شخص ثالث، با نسخهٔ مشخص استفاده می‌کنند. این فرمان‌ها برای PowerShell، Bash و ترمینال macOS یکسان‌اند. گزینهٔ `--copy` به دسترسی ساخت symlink نیاز ندارد.

**Codex**

```sh
npx --yes skills@1.7.2 add MrAshki/agentic-botcamp-checklist-skill --skill ai-project-navigator --agent codex --global --copy --yes
```

**Gemini CLI**

```sh
npx --yes skills@1.7.2 add MrAshki/agentic-botcamp-checklist-skill --skill ai-project-navigator --agent gemini-cli --global --copy --yes
```

**Claude Code**

```sh
npx --yes skills@1.7.2 add MrAshki/agentic-botcamp-checklist-skill --skill ai-project-navigator --agent claude-code --global --copy --yes
```

برای Codex پس از نصب، جلسهٔ تازه باز کنید. در Gemini CLI، `/skills reload` و سپس `/skills list` را اجرا کنید. Claude Code معمولاً تغییر پوشهٔ موجود را در همان جلسه می‌بیند؛ اگر پوشهٔ اصلی اسکیل‌ها تازه ساخته شده است، `/reload-skills` را اجرا کنید. نصب در سطح کاربر است و به پروژهٔ جاری محدود نمی‌شود. نصب در WSL و نصب در ویندوز دو محیط جدا هستند.

> این سه نام، ابزارهای مقصد هستند؛ عوض‌کردن مدل API به‌تنهایی محل نصب اسکیل را تغییر نمی‌دهد.

## استفاده

در **Codex**:

```text
با $ai-project-navigator برای پروژه‌ام مسیر و چک‌لیست اختصاصی بساز.
می‌خواهم ریزش مشتری را پیش‌بینی کنم؛ ۲۰۰۰ ردیف داده با برچسب دارم، GPU ندارم و ده روز برای دموی کلاسی وقت دارم.
```

در **Claude Code**:

```text
/ai-project-navigator می‌خواهم ریزش مشتری را پیش‌بینی کنم؛ ۲۰۰۰ ردیف داده با برچسب دارم، GPU ندارم و ده روز برای دموی کلاسی وقت دارم.
```

در **Gemini CLI**:

```text
از اسکیل ai-project-navigator استفاده کن. می‌خواهم ریزش مشتری را پیش‌بینی کنم؛ ۲۰۰۰ ردیف داده با برچسب دارم، GPU ندارم و ده روز برای دموی کلاسی وقت دارم.
```

نیازی به پرکردن فرم نیست. ایده و شرایطتان را به زبان عادی بگویید. اگر هدف هنوز مشخص نباشد، دستیار فقط سؤال‌های مؤثر بر مسیر را می‌پرسد. سقف هر نوبت ۱۰ سؤال است، اما معمولاً تعداد کمتری لازم می‌شود. تا روشن‌شدن انتخاب اصلی، دستیار از انتخاب زودهنگام فناوری خودداری می‌کند.

## نمونهٔ خروجی

نمونهٔ خلاصه و نمایشی برای پروژهٔ ریزش مشتری:

**مسیر:** تعریف ریزش و دادهٔ قابل‌استفاده ← طرح ارزیابی ← مقایسهٔ مدل‌های ساده روی CPU ← آماده‌سازی دمو.

**چک‌لیست الان:**

- [ ] تعریف ریزش را مشخص کن — تکمیل وقتی: بازهٔ زمانی پیش‌بینی و معنای دقیق برچسب روشن باشند.
- [ ] ستون‌های قابل‌استفاده را تعیین کن — تکمیل وقتی: اطلاعاتی که بعد از ریزش تولید شده‌اند از ورودی کنار گذاشته شوند.
- [ ] طرح جداسازی داده را انتخاب کن — تکمیل وقتی: زمان و مشتری‌های تکراری در طرح لحاظ شده باشند.
- [ ] معیار موفقیت و Baseline را تعیین کن — تکمیل وقتی: معلوم باشد نتیجه با چه روش ساده‌ای و تحت چه هزینهٔ خطایی مقایسه می‌شود.
- [ ] دامنهٔ دمو را محدود کن — تکمیل وقتی: یک خروجی ضروری و موارد خارج از دامنه مشخص باشند.

**فعلاً لازم نیست:** Agent و RAG برای این مسئله؛ خرید GPU پیش از آزمایش روش ساده.

**منابع مرتبط دوره:**

- جلسهٔ ۱ — داده، سوخت هر AI Agent: بررسی کیفیت، Split و جلوگیری از Data Leakage.
- جلسهٔ ۲ — یادگیری ماشین، از کل به جزء: انتخاب Baseline جدولی و معیار ارزیابی.

این خروجی ثابت نیست. برای مقایسهٔ صوت، RAG اسناد یا ابزار دارای دسترسی بیرونی، بندها تغییر می‌کنند.

## روش کار

۱. **شناخت شرایط:** هدف، مخاطب، داده و مرحلهٔ فعلی را از توضیح شما می‌گیرد. زمان، بودجه، سخت‌افزار و حساسیت داده فقط وقتی پیگیری می‌شوند که مسیر را تغییر دهند.

۲. **انتخاب مسیر:** ساده‌ترین گزینهٔ سازگار با شرایط را پیشنهاد می‌دهد؛ راه‌حل بدون AI هم گزینه است. جذاب‌بودن یک فناوری دلیل انتخاب آن نیست.

۳. **انتخاب بندهای مرتبط:** از هشت چک‌لیست دوره، موارد لازم را انتخاب می‌کند، تکراری‌ها را ادغام می‌کند و آن‌ها را برای همان پروژه بازنویسی می‌کند.

۴. **ساخت خروجی کوتاه:** مسیر ۳ تا ۵ مرحله‌ای، معمولاً ۵ تا ۸ بند برای مرحلهٔ فعلی، نشانهٔ تکمیل، موارد غیرضروری و فرض‌های مؤثر.

۵. **تغییر با شرایط شما:** اگر هدف یا منابع عوض شد، فقط تصمیم‌ها و بندهای متأثر را به‌روز می‌کند.

```text
شرایط عوض شده: به‌جای دموی کلاسی، یک صفحهٔ عمومی با نتایج می‌خواهم؛ دادهٔ خام باید خصوصی بماند. مسیر و بندهای متأثر را به‌روز کن.
```

اسکیل، دستورالعمل و منابعی است که ابزار خودتان می‌خواند؛ سرویس مستقلی برای بارگذاری پروژه یا نگهداری اطلاعات شما ندارد. این موضوع، سیاست حریم خصوصی ابزار یا ارائه‌دهندهٔ مدل شما را تغییر نمی‌دهد.

## چه خروجی‌ای انتظار داشته باشیم؟

- راهنمای تصمیم‌گیری و چک‌لیست متناسب با شرایط؛
- سؤال کوتاه در ابهامی که واقعاً روی مسیر اثر دارد؛
- تمایز دموی کلاسی با سرویس عملیاتی؛
- جداکردن متن دوره از نکات افزوده؛
- نمایش منبع به‌صورت نام جلسه و موضوع استفاده‌شده، نه شناسه‌های فنی داخلی؛
- حفظ محدودیت‌ها و پرهیز از وعدهٔ دقت، هزینه یا زمان تضمین‌شده.

دامنهٔ این اسکیل انتخاب مسیر است؛ کدنویسی، اجرای پروژه، ممیزی فنی و صدور تأییدیهٔ امنیت یا انتشار در آن تعریف نشده‌اند. خالی‌بودن چک‌باکس به معنی وجود نقص اثبات‌شده نیست.

## بررسی نصب، به‌روزرسانی و حذف

بررسی نصب، با جایگزینی شناسهٔ ابزار خودتان (`codex`، `gemini-cli` یا `claude-code`):

```sh
npx --yes skills@1.7.2 ls --global --agent codex
```

برای به‌روزرسانی، همان فرمان نصب مربوط به ابزار خودتان را دوباره اجرا کنید؛ محتوای نصب‌شده از ریپو تازه می‌شود. اگر فایل نصب‌شده را شخصی‌سازی کرده‌اید، پیش از نصب مجدد کپی جدا نگه دارید.

حذف این اسکیل از همهٔ ابزارهایی که در سطح کاربر آن را نصب کرده‌اید:

```sh
npx --yes skills@1.7.2 remove ai-project-navigator --global --yes
```

اگر فقط یکی از ابزارها باید اسکیل را از دست بدهد، مسیر نصب را بررسی کنید؛ مسیر `.agents/skills` می‌تواند بین چند ابزار مشترک باشد. حذف با فیلتر Gemini در نصب‌کنندهٔ نسخهٔ 1.7.2 در آزمون پروژه‌ای کامل نبود؛ برای حذف کامل از فرمان بالا استفاده کنید.

### بدون Node.js

می‌توانید پوشهٔ کامل [`skills/ai-project-navigator`](skills/ai-project-navigator) را با Git یا دانلود ریپو در محل اسکیل‌های ابزار قرار دهید. مسیرهای مستند در محیط‌های معمول:

- Codex: `~/.agents/skills/ai-project-navigator/`
- Gemini CLI: `~/.gemini/skills/ai-project-navigator/`؛ مسیر اشتراکی `.agents/skills` هم پشتیبانی می‌شود.
- Claude Code: `~/.claude/skills/ai-project-navigator/`

`~` پوشهٔ کاربر همان محیط است. در نسخه‌ها یا محیط‌های مدیریت‌شده، تنظیمات سازمان می‌تواند دسترسی به اسکیل‌ها را محدود کند. راهنمای کامل و روش جایگزین Gemini در [INSTALL.md](INSTALL.md) آمده است.

## ساختار ریپو

- `skills/ai-project-navigator/SKILL.md`: روش تعامل، انتخاب مسیر و ساخت چک‌لیست.
- `skills/ai-project-navigator/references/01-*` تا `08-*`: هشت چک‌لیست با ۱۵۹ شناسهٔ ثابت.
- `references/course-session-00.md` تا `course-session-05.md`: خلاصهٔ مسیریابی‌شدهٔ محتوای جلسه‌های دوره؛ داخل پوشهٔ اسکیل.
- `references/course-topic-map.md`: نگاشت موضوع به نام رسمی جلسه و مرجع مرتبط.
- `references/selection-rules.md`: شرط کاربرد، اطلاعات لازم، مرحله و نشانهٔ تکمیل بندها؛ داخل پوشهٔ اسکیل.
- `references/interpretation.md`: نکات تکمیلی و رفع برداشت‌های بیش‌ازحد کلی؛ داخل پوشهٔ اسکیل.
- `INSTALL.md`: دستورالعمل نصب برای ایجنت و نصب دستی.
- `scripts/`: کنترل صحت بسته و آزمون نصب؛ برای استفادهٔ روزمره لازم نیستند.
- `.github/workflows/validate.yml`: اجرای کنترل‌ها در Linux، Windows و macOS.

## توسعه و آزمون

پیش‌نیاز توسعه: Python 3.10+، Git و Node.js 22.20+.

```sh
python scripts/validate.py
python scripts/smoke_install.py
```

آزمون نصب، نسخهٔ واقعی `skills@1.7.2` را در پوشه‌های موقت اجرا می‌کند: نصب برای هر سه ابزار، تطبیق تمام فایل‌ها، مشاهده در فهرست، نصب مجدد، حذف و حفظ یک اسکیل نامرتبط. به پوشهٔ اسکیل‌های حساب شخصی دست نمی‌زند. برای نتایج و محدودیت‌ها [گزارش آزمون](docs/TESTING.md) را بخوانید.

برای پیشنهاد بهبود، یک Issue با توضیح پروژه، شرایط ورودی، پاسخ دریافتی و بخشی که مفید نبوده ثبت کنید. نمونه را از اطلاعات شخصی پاک کنید. هدف، بندهای دقیق‌تر و سؤال‌های کمتر است؛ افزودن بند صرفاً برای طولانی‌ترشدن چک‌لیست مفید نیست.

## منبع و انتساب

مبنای آموزشی: **محتوای جلسه‌های صفر تا پنج بوت‌کمپ هوش مصنوعی رضا شکرزاد** بر اساس PDFهای ارائه‌شده توسط مالک پروژه، به‌همراه چک‌لیست‌های جلسهٔ ۵، اسلایدهای ۲۷ تا ۳۴. [مرجع آنلاین چک‌لیست‌ها](https://shokrzad.com/ai/api/icourse/courses/ai-agents-bootcamp/slides/session-5-open-models#27).
