# سخت‌افزار، حافظه و هزینه

## عامل اصلی سرعت

در مرحله تولید Token، پهنای باند حافظه اغلب عامل مهمی است؛ زیرا وزن‌ها بارها از حافظه خوانده می‌شوند. ظرفیت حافظه تعیین می‌کند مدل و KV Cache جا می‌شوند یا نه. قدرت محاسباتی، Batch و Kernel نیز مهم‌اند.

## انواع سخت‌افزار

- CPU: در دسترس و مناسب مدل کوچک یا سرعت پایین‌تر
- GPU مصرف‌کننده: مناسب آزمایش و مدل‌های متوسط، با محدودیت VRAM
- Workstation GPU: حافظه و قابلیت حرفه‌ای بیشتر
- Data Center GPU: Throughput و قابلیت مقیاس بالا با هزینه زیاد
- Apple Silicon: حافظه یکپارچه و گزینه مناسب برای برخی مدل‌های بزرگ Quantized
- NPU و Edge AI: مصرف توان پایین برای مدل‌های کوچک و وظایف خاص
- FPGA یا ASIC: شتاب‌دهنده تخصصی برای کاربرد مشخص

## حافظه یکپارچه

در Apple Silicon و برخی سامانه‌های Ryzen AI Max، CPU و GPU از حافظه مشترک استفاده می‌کنند. این طراحی می‌تواند اجرای مدل بزرگ‌تر از VRAM یک GPU مصرف‌کننده را ممکن کند. سرعت و سازگاری Runtime همچنان باید آزمایش شوند.

## Mini PC و Cluster

Mini PC می‌تواند برای Agent سبک، RAG، مدل Quantized یا توسعه محلی مناسب باشد. Cluster کردن چند دستگاه همیشه حافظه آن‌ها را به‌شکل ساده یکی نمی‌کند. شبکه، Sharding، نرم‌افزار توزیع‌شده و سربار ارتباط اهمیت دارند.

## محاسبه هزینه

هزینه کل مالکیت شامل این موارد است:

- قیمت دستگاه یا اجاره GPU
- برق و خنک‌سازی
- نگهداری، خرابی و جایگزینی
- زمان DevOps و امنیت
- ظرفیت موردنیاز در اوج بار
- هزینه فرصت سخت‌افزار بلااستفاده

قیمت API باید بر اساس Token ورودی، خروجی، Cache و حجم واقعی Workflow محاسبه شود. قیمت اسلاید فقط نمونه زمان ارائه است و نباید به‌عنوان قیمت روز استفاده شود.

## روش انتخاب

1. مدل یا چند مدل کاندید را تعیین کنید.
2. حافظه وزن و KV Cache را برآورد کنید.
3. Throughput و Latency هدف را مشخص کنید.
4. مدل را روی سخت‌افزار واقعی Benchmark کنید.
5. کیفیت را روی Golden Set بسنجید.
6. هزینه کل API و محلی را در دوره زمانی یکسان مقایسه کنید.
