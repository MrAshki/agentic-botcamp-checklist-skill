# جلسه ۵ - مدل‌های متن‌باز و LLM محلی

## هدف این پوشه

این پوشه محتوای جلسه ۵ بوتکمپ را به‌شکل ساختاریافته نگه می‌دارد. مخاطب آن همه دانشجویان دوره هستند.

این پوشه فعلا به اسکیل `ai-project-navigator` متصل نیست. اتصال به اسکیل پس از استخراج و بررسی همه جلسه‌ها انجام می‌شود.

## منبع

- عنوان رسمی: «جلسه ۵ - مدل‌های متن‌باز و LLM محلی»
- تعداد صفحه: ۳۴
- مدرس: رضا شکرزاد
- نقش جلسه: انتخاب و اجرای مدل محلی، برآورد حافظه و سخت‌افزار، استقرار، امنیت و جمع‌بندی چک‌لیست‌های دوره

## فایل‌ها

- `01-page-index.md`: نمایه همه ۳۴ صفحه
- `02-core-content.md`: مفاهیم اصلی مدل‌های باز و اجرای محلی
- `03-model-and-runtime-selection.md`: انتخاب مدل، Quantization و Runtime
- `04-hardware-and-cost.md`: حافظه، سخت‌افزار و هزینه
- `05-serving-tuning-and-security.md`: Serving، Fine-tune، RLHF و امنیت
- `06-project-and-local-coding.md`: پروژه مالی و اتصال OpenCode به مدل محلی

- `08-review-notes.md`: وضعیت استخراج و نکات تفسیری

## قرارداد محتوا

- «محتوای دوره» نکته‌ای است که مستقیم در اسلایدها آمده است.
- قیمت‌ها، رتبه‌ها، نام مدل‌ها و مشخصات سخت‌افزار زمان‌حساس هستند.
- اجرای محلی یک گزینه مهندسی است و پیش‌فرض همه پروژه‌ها نیست.
- چک‌لیست‌های صفحه‌های ۲۷ تا ۳۴، مرجع اصلی جمع‌بندی دوره هستند.
- PDF مرجع نهایی جدول‌ها، نمودارها و جزئیات تصویری است.
