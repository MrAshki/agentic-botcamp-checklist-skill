# جلسه صفر - از تورینگ تا Agent

## هدف این پوشه

این پوشه محتوای جلسه صفر بوتکمپ را به‌شکل ساختاریافته نگه می‌دارد. مخاطب آن همه دانشجویان دوره هستند.

این پوشه فعلا به اسکیل `ai-project-navigator` متصل نیست. اتصال به اسکیل پس از استخراج و بررسی همه جلسه‌ها انجام می‌شود.

## منبع

- عنوان رسمی: «جلسه صفر - از تورینگ تا Agent»

- مدرس: رضا شکرزاد
- نقش جلسه: معرفی دوره، ساخت واژگان مشترک و ارائه نقشه کلی AI و Agentic AI
