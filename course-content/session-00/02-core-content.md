# محتوای اصلی جلسه صفر

## ۱. هدف جلسه و دوره

محتوای دوره سه سطح رشد را معرفی می‌کند:

1. کاربر: با یک مدل گفتگو می‌کند و خروجی را مصرف می‌کند.
2. سازنده: Prompt می‌نویسد، از API استفاده می‌کند و کارهای تکراری را خودکار می‌کند.
3. معمار سیستم: داده، مدل، Agent و ارزیابی را کنار هم می‌گذارد و یک محصول قابل استفاده می‌سازد.

هدف دوره ساخت مدل از صفر نیست. هدف این است که دانشجو مدل‌های آماده را با داده، ابزار و Context درست به کار بگیرد.

## ۲. خانواده مفاهیم AI

- AI دامنه کلی سیستم‌هایی است که یک کار هوشمندانه انجام می‌دهند.
- ML بخشی از AI است که الگو را از داده یاد می‌گیرد.
- Deep Learning بخشی از ML است و از شبکه‌های عصبی چندلایه استفاده می‌کند.
- GenAI محتوای جدید تولید می‌کند.
- LLM نوعی مدل زبانی بزرگ و یکی از مدل‌های اصلی GenAI است.

## ۳. چرا رشد AI سریع شد

سه عامل اصلی عبارت‌اند از:

- داده بیشتر و متنوع‌تر
- توان محاسباتی، به‌ویژه GPU
- الگوریتم‌ها و معماری‌های بهتر، مانند Backpropagation، شبکه عمیق و Transformer

سرمایه و نیروی متخصص نیز سرعت این چرخه را بیشتر کردند.

## ۵. از Transformer تا Agent

Transformer با Self-Attention رابطه بین توکن‌ها را در متن محاسبه می‌کند. این معماری امکان آموزش موازی در مقیاس بزرگ را بهتر کرد.

مسیر بعدی چنین است:

- مدل زبانی پاسخ تولید می‌کند.
- Function Calling امکان فراخوانی API را می‌دهد.
- Computer Use امکان کار با رابط تصویری را می‌دهد.
- MCP اتصال استاندارد مدل به ابزار و داده را آسان می‌کند.
- Coding Agent می‌تواند در محیط توسعه کد را بررسی، تغییر و اجرا کند.
- A2A برای ارتباط Agentها مطرح می‌شود.

## ۶. مبانی یادگیری ماشین و LLM

در برنامه‌نویسی سنتی، داده و قانون به خروجی می‌رسند. در یادگیری ماشین، داده و پاسخ‌های نمونه برای یادگیری قانون استفاده می‌شوند.

انواع یادگیری معرفی‌شده:

- نظارت‌شده: داده برچسب دارد.
- بدون نظارت: مدل ساختار یا گروه‌ها را پیدا می‌کند.
- تقویتی: مدل از پاداش و جریمه یاد می‌گیرد.
- خودنظارتی: برچسب از خود داده ساخته می‌شود؛ پیش‌بینی توکن بعدی نمونه آن است.

مراحل آماده‌سازی یک LLM:

1. Pre-training برای یادگیری عمومی از حجم زیاد متن
2. SFT برای پیروی از دستور با نمونه‌های خوب
3. RLHF برای جهت‌دهی با بازخورد انسان
4. Reasoning RL برای تمرین مسئله‌های دارای پاسخ قابل بررسی

## ۷. کنترل‌های مهم مدل

- Token: واحد پردازش و قیمت‌گذاری متن
- Context Window: مقدار اطلاعاتی که مدل هم‌زمان می‌بیند
- Temperature: میزان تنوع خروجی
- System Prompt: قواعد و نقش ثابت سیستم
- Max Tokens: سقف طول خروجی و یکی از کنترل‌های هزینه
- Top-p: محدودکردن انتخاب به توکن‌های محتمل‌تر

## ۸. Embedding و Context

Embedding یک نمایش عددی از معنا است. کاربردهای آن عبارت‌اند از:

- جست‌وجوی معنایی
- بازیابی بخش مرتبط سند در RAG
- پیشنهاددهی
- خوشه‌بندی

روند مهارت کار با LLM در اسلایدها چنین بیان می‌شود:

- Prompt Engineering: چگونه درخواست را بنویسیم؟
- Context Engineering: مدل چه اطلاعاتی را باید ببیند؟
- Agent Design: سیستم چگونه کار را تا پایان انجام دهد؟

## ۹. نقشه توانایی‌های AI

گروه‌های اصلی توانایی:

- متن: نوشتن، ترجمه، خلاصه، استخراج و دسته‌بندی
- کد: پیشنهاد، ساخت نمونه و عامل کدنویسی
- تصویر: تولید، ویرایش، درک و OCR
- صدا: تبدیل گفتار و متن، Voice Agent و شبیه‌سازی صدا
- ویدیو: تولید، خلاصه، جست‌وجوی صحنه و تحلیل
- چندوجهی: ترکیب چند نوع ورودی و خروجی
- داده: Text-to-SQL، داشبورد و تحلیل چندمرحله‌ای
- ML کلاسیک: پیش‌بینی روی داده جدولی
- علم و حوزه تخصصی: پزشکی، مالی، حقوق، مهندسی و علوم پایه
- رباتیک: ترکیب بینایی، زبان و عمل
- Computer Use: کار با رابط کاربری در نبود API مناسب

## ۱۰. ML کلاسیک هنوز مهم است

اسلایدها تأکید می‌کنند که هر مسئله به LLM نیاز ندارد. برای داده‌های جدولی، مدل‌هایی مانند XGBoost اغلب ارزان‌تر، سریع‌تر و توضیح‌پذیرتر هستند.

نمونه مسائل:

- ریزش مشتری
- پیش‌بینی تقاضا
- کشف تقلب
- اعتبارسنجی
- نگهداری پیش‌بینانه
- قیمت‌گذاری پویا

## ۱۱. تعریف Agent

Agent سیستمی است که:

1. هدف را دریافت می‌کند.
2. وضعیت را مشاهده می‌کند.
3. درباره گام بعد تصمیم می‌گیرد.
4. ابزار را فراخوانی می‌کند.
5. نتیجه را می‌بیند.
6. تا رسیدن به هدف ادامه می‌دهد.

اجزای اصلی:

- LLM به‌عنوان بخش تصمیم‌گیری
- Tools برای انجام عمل
- Memory برای نگهداری اطلاعات کوتاه‌مدت یا بلندمدت
- Planning برای شکستن هدف و بازبینی مسیر

## ۱۲. طیف خودمختاری

سطح‌های معرفی‌شده:

1. Chatbot: فقط پاسخ می‌دهد.
2. Copilot: پیشنهاد می‌دهد و انسان اجرا می‌کند.
3. Workflow: مسیر از قبل طراحی شده است و مدل در بعضی گام‌ها استفاده می‌شود.
4. Agent: مسیر و ابزار را با توجه به نتیجه هر گام انتخاب می‌کند.
5. Multi-agent: چند عامل با نقش‌های جدا با هم کار می‌کنند.

## ۱۳. MCP

MCP یک پروتکل باز برای اتصال برنامه میزبان AI به ابزارها و داده‌ها است.

اجزای اصلی:

- Host یا Client: برنامه‌ای که مدل در آن کار می‌کند.
- MCP Server: برنامه‌ای که یک سرویس را با قرارداد استاندارد ارائه می‌کند.
- Tools: عمل‌هایی که مدل می‌تواند انجام دهد.
- Resources: داده‌هایی که مدل می‌تواند بخواند.
- Prompts: الگوهای آماده درخواست.

## ۱۴. الگوی فرصت AI

اسلایدها یک الگوی مشترک ارائه می‌کنند:

`کار تکراری + داده زیاد + تصمیم‌های پرتعداد = فرصت AI`

این الگو در خرده‌فروشی، بانک، سلامت، منابع انسانی، فروش، آموزش، صنعت، حقوق، بازاریابی، لجستیک، کشاورزی، دولت و کسب‌وکار کوچک دیده می‌شود.

## ۱۵. ریسک‌ها

ریسک‌های اصلی جلسه:

- Hallucination: تولید پاسخ روان ولی نادرست
- Prompt Injection: دستور مخرب در ورودی، سند یا صفحه وب
- نشت داده: قراردادن اطلاعات حساس در سرویس نامناسب
- Excessive Agency: دادن دسترسی بیش از نیاز
- هزینه توکن و تأخیر
- مقررات، مجوز و حق نشر

روش‌های کاهش Hallucination:

- پاسخ از سند واقعی با RAG
- ارجاع و نقل‌قول
- راستی‌آزمایی با ابزار
- ارزیابی منظم
- تأیید انسانی برای کار حساس

## ۱۶. چشم‌انداز و مهارت‌های مهم

چشم‌اندازهای مطرح‌شده:

- چند Agent در کنار هر تیم انسانی
- شرکت‌های AI-native
- دستیار شخصی دارای حافظه
- مدل‌های کوچک روی دستگاه
- تغییر رابط کاربری از کلیک به واگذاری هدف

مهارت‌های پایدار:

- تعریف مسئله
- دانش عمیق حوزه
- ارزیابی و قضاوت
- نوشتن دستور کار دقیق
- سواد داده
- تفکر سیستمی
- ارتباط و داستان‌گویی
- اخلاق و مسئولیت
