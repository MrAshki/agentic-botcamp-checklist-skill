# قواعد تصمیم‌گیری جلسه صفر

## قاعده ۱ - ساده‌ترین راهی را انتخاب کنید که کار می‌کند

از Workflow شروع کنید. فقط وقتی خودمختاری لازم است از Agent استفاده کنید.

### Workflow مناسب است اگر

- گام‌ها از قبل مشخص‌اند.
- تکرارپذیری و اطمینان مهم است.
- هزینه و سرعت مهم‌اند.
- سیستم باید به‌آسانی تست و ممیزی شود.

### Agent مناسب است اگر

- مسیر از قبل مشخص نیست.
- تعداد گام‌ها متغیر است.
- نتیجه هر گام مسیر بعدی را تغییر می‌دهد.
- ارزش کار هزینه و ریسک بیشتر را توجیه می‌کند.

## قاعده ۲ - هر مسئله به LLM نیاز ندارد

- برای داده جدولی، ابتدا یک مدل کلاسیک را بررسی کنید.
- برای مسیر ثابت چندمرحله‌ای، ابتدا Workflow را بررسی کنید.
- برای دانش خصوصی یا به‌روز، RAG را بررسی کنید.
- برای رابط قدیمی بدون API، Computer Use را فقط پس از بررسی API به کار ببرید.
- برای کار ساده، مدل کوچک‌تر را بررسی کنید.

## قاعده ۳ - توانایی AI را برای هر کار جدا بسنجید

موفقیت مدل در یک کار، موفقیت آن در کار دیگر را ثابت نمی‌کند. برای هر کار، نمونه واقعی و معیار مستقل بسازید.

## قاعده ۴ - انسان باید در تصمیم حساس حضور داشته باشد

پیش از این کارها تأیید انسانی بگیرید:

- ارسال پیام یا ایمیل از طرف سازمان
- پرداخت و تراکنش مالی
- حذف یا تغییر داده
- تصمیم درباره استخدام، وام یا درمان
- هر عمل برگشت‌ناپذیر

سطح نظارت را مشخص کنید:

- In the loop: تأیید پیش از عمل حساس
- On the loop: نظارت و امکان توقف
- Out of the loop: اجرای خودکار فقط برای کار کم‌ریسک

## قاعده ۵ - کمترین دسترسی لازم را بدهید

- ابزار فقط به داده و عمل لازم دسترسی داشته باشد.
- داده حساس را در سرویس عمومی وارد نکنید.
- Secret، Token و رمز عبور را در Prompt قرار ندهید.
- ورودی بیرونی را قابل اعتماد فرض نکنید.
- خروجی Agent را پیش از عمل حساس اعتبارسنجی کنید.

## قاعده ۶ - هزینه و تأخیر را از ابتدا حساب کنید

برای برآورد اولیه این موارد را ثبت کنید:

- تعداد درخواست روزانه
- توکن ورودی و خروجی هر درخواست
- استفاده از مدل استدلالی
- زمان پاسخ قابل قبول
- هزینه ماهانه قابل قبول

اهرم‌های کاهش هزینه:

- Routing بین مدل کوچک و بزرگ
- Prompt Caching
- Batch برای کار غیرفوری
- Context کوتاه و دقیق

## قاعده ۹ - کار فعلی را از کوچک شروع کنید

1. سه کار تکراری و وقت‌گیر را فهرست کنید.
2. زمان و خطای هر کار را اندازه بگیرید.
3. برای یک کار، یک دستیار یا Workflow ساده بسازید.
4. زمان ذخیره‌شده و کیفیت نتیجه را گزارش کنید.
