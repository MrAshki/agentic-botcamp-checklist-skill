# جلسه ۴ - Agentic AI در عمل

## هدف این پوشه

این پوشه محتوای جلسه ۴ بوتکمپ را به‌شکل ساختاریافته نگه می‌دارد. مخاطب آن همه دانشجویان دوره هستند.
