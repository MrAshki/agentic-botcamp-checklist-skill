# Workflow، معماری و خودمختاری

## الگوهای Workflow

### Prompt Chaining

کار به چند مرحله ثابت تقسیم می‌شود. خروجی هر مرحله ورودی مرحله بعد است. Gate می‌تواند ساختار یا کیفیت خروجی را کنترل کند.

### Routing

یک Router درخواست را به مسیر مناسب می‌فرستد. این الگو برای Intentهای محدود و مسیرهای روشن مناسب است.

### Parallelization

چند کار مستقل هم‌زمان اجرا می‌شوند. نتیجه‌ها با رأی‌گیری یا ترکیب خروجی جمع می‌شوند.

### Orchestrator-Workers

Orchestrator کار را به بخش‌های کوچک تقسیم می‌کند و Workerها آن‌ها را انجام می‌دهند.

### Evaluator-Optimizer

یک بخش خروجی را تولید می‌کند و بخش دیگر آن را با معیار مشخص ارزیابی می‌کند. حلقه باید شرط توقف داشته باشد.

### Autonomous Agent

Agent مسیر و ابزار را پویا انتخاب می‌کند. این الگو فقط زمانی مناسب است که تعداد و ترتیب قدم‌ها از پیش معلوم نباشد و ارزش آن از هزینه و ریسک بیشتر باشد.

## Single-Agent یا Multi-Agent

Single-Agent معمولا انتخاب اول است. Context مشترک، اشکال‌زدایی و استقرار آن ساده‌تر است.

Multi-Agent زمانی ارزش دارد که:

- نقش‌ها و مسئولیت‌ها واقعا جدا باشند.
- هر نقش به Context یا ابزار متفاوت نیاز داشته باشد.
- جداسازی مجوزها مهم باشد.
- ارزیابی مستقل یا Handoff روشن لازم باشد.

الگوهای مطرح:

- Supervisor یا Hierarchical
- Handoff یا Network
- چند Agent متخصص با Coordinator

ریسک‌ها شامل افزایش هزینه Token، خطا در Handoff، Cascading Failure، اشکال‌زدایی دشوار و Context تکراری هستند.

## سطوح خودمختاری

1. Operator: انسان هر قدم را فرمان می‌دهد.
2. Collaborator: Agent پیشنهاد می‌دهد و انسان با آن همکاری می‌کند.
3. Consultant: Agent مسیر را تحلیل می‌کند، اما تصمیم حساس با انسان است.
4. Approver: Agent کار را آماده می‌کند و پیش از اجرا تأیید می‌گیرد.
5. High-Autonomy: Agent در محدوده مشخص مستقل عمل می‌کند و Kill Switch دارد.

سطح خودمختاری باید بر اساس هزینه خطا، برگشت‌پذیری، حساسیت داده و نقش کاربر تعیین شود.

## الگوهای Human-in-the-loop

- Approve پیش از عمل حساس
- Edit برای اصلاح پیشنهاد
- Reject برای رد عمل
- Escalate برای ارجاع به انسان یا نقش بالاتر
- Interrupt برای توقف اجرای جاری

ریسک Automation Bias باید صریح باشد. انسان ممکن است پیشنهاد سیستم را بدون بررسی کافی بپذیرد.

## سطوح استقرار

- Copilot: پیشنهاد می‌دهد؛ انسان اجرا می‌کند.
- Workflow خودکار: مسیر ثابت و قابل‌کنترل دارد.
- Agent در Sandbox: ابزار و داده محدود دارد.
- Agent با HITL در Production: عمل حساس با تأیید انجام می‌شود.
- Agent خودگردان: فقط در دامنه کم‌خطر، با سقف بودجه، Audit و Kill Switch.

افزایش خودمختاری باید مرحله‌ای و بر اساس نتیجه ارزیابی باشد.
