# مسیر پروژه و ارتباط با Agentic AI

## نمونه مسیر پروژه دسته‌بندی متن

1. مسئله و برچسب‌ها را تعریف کنید.
2. داده را جمع‌آوری و برچسب‌ها را کنترل کنید.
3. طول متن، توزیع کلاس و خطاهای داده را بررسی کنید.
4. متن فارسی را با نیاز پروژه نرمال و توکن‌بندی کنید.
5. یک خط پایه TF-IDF و Logistic Regression، Naive Bayes یا SVM بسازید.
6. با Macro-F1، ماتریس درهم‌ریختگی و بررسی نمونه‌های خطا ارزیابی کنید.
7. فقط اگر ارزش و منابع کافی وجود دارد، Fine-tune مدل ازپیش‌آموزش‌دیده را مقایسه کنید.
8. مدل برگزیده را به‌شکل تابع، API یا ابزار در اختیار سیستم قرار دهید.

## نگاشت مفاهیم جلسه به Agent

| مفهوم یادگیری ماشین | نقش ممکن در سیستم Agentic |
|---|---|
| Transformer یا LLM | فهم درخواست، استدلال، برنامه‌ریزی و انتخاب ابزار |
| Embedding و KNN | حافظه معنایی و بازیابی در RAG |
| دسته‌بندی متن | Router، تشخیص قصد یا Guardrail کوچک |
| NER | استخراج پارامترهای لازم برای فراخوانی ابزار |
| مدل جدولی یا پیش‌بینی سری زمانی | یک ابزار تخصصی برای پیش‌بینی |
| خوشه‌بندی | گروه‌بندی سندها، تیکت‌ها یا کاربران |
| تشخیص ناهنجاری | هشدار یا Trigger برای شروع یک Workflow |
| بینایی ماشین و ASR | ورودی دیداری و شنیداری |
| یادگیری تقویتی | یادگیری رفتار چندمرحله‌ای یا هم‌ترازی، در صورت نیاز واقعی |
| Ensemble | رأی‌گیری، Self-consistency یا چند ارزیاب |
| معیار و Cross-Validation | پایه ارزیابی و کنترل کیفیت |

## مرز مهم

وجود LLM به این معنی نیست که پروژه باید Agent خودمختار باشد. اگر مراحل ثابت و معلوم هستند، Workflow ساده‌تر است. مدل کلاسیک یا سرویس آماده نیز می‌تواند فقط یکی از ابزارهای Workflow باشد.

## منابع فارسی نام‌برده در جلسه

- ParsBERT برای برخی وظایف فهم متن فارسی
- مدل‌های embedding چندزبانه مانند multilingual-e5
- Whisper برای تبدیل گفتار به متن
- مجموعه‌داده‌هایی مانند PersianNER، ARMAN و ParsinLU
- داده دیدگاه‌های فارسی و ابزارهای پیش‌پردازش مانند Hazm و Parsivar

این نام‌ها بخشی از محتوای زمان ارائه هستند. پیش از استفاده، وضعیت نگهداری، مجوز، کیفیت، نیاز سخت‌افزاری و نتیجه روی داده پروژه باید بررسی شود.
