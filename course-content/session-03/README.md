# جلسه ۳ - از API تا RAG

## هدف این پوشه

این پوشه محتوای جلسه ۳ بوتکمپ را به‌شکل ساختاریافته نگه می‌دارد. مخاطب آن همه دانشجویان دوره هستند.

این پوشه فعلا به اسکیل `ai-project-navigator` متصل نیست. اتصال به اسکیل پس از استخراج و بررسی همه جلسه‌ها انجام می‌شود.

## منبع

- عنوان رسمی: «جلسه ۳ - از API تا RAG»
- تعداد صفحه: ۳۰
- مدرس: رضا شکرزاد
- نقش جلسه: اتصال اجزای محصول هوش مصنوعی، کار با API و ساخت سامانه RAG قابل‌ردیابی

## فایل‌ها

- `01-page-index.md`: نمایه همه ۳۰ صفحه
- `02-core-content.md`: محتوای آموزشی دسته‌بندی‌شده
- `03-api-and-product-architecture.md`: API، معماری محصول و اجزای Production
- `04-rag-pipeline.md`: محدودیت‌های LLM و خط لوله RAG
